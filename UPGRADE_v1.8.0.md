# Bitcoin Miner Studio v1.8.0 — Diagnostics & Support Center Upgrade

Upgrade from v1.7.0 by replacing the application source folder with the complete signed v1.8.0 release. Keep user data under `.bitcoin-miner-studio`; do not merge protected source files individually between versions.

## v1.8.0 additions

- Diagnostics & Support Center sidebar workspace
- Quick and Full read-only diagnostics
- Health scoring by operational category
- Issue classification and guided remediation
- Local privacy-sanitized support bundles
- Support-safe system snapshot and report copying

## Preserved functionality

Mining Academy, Benchmark Lab 2.0, Pool Profiles/PowerTools, ASIC Control/Solo Bridge, Bitcoin Core integration, Monitoring, Tray/Background operation, Release Readiness and Purple Dragon Security are preserved.

## Security

Use the complete signed v1.8.0 folder. Purple Dragon trust validates the exact protected-file set for this release; modifying protected files after signing causes trust verification to fail until the intended release is rebuilt and re-signed.
